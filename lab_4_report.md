# Отчет по лабораторной работе 4 "Biopython"

## Цель
Научиться работать с форматами биологических последовательностей GenBank, выполнять базовую фильтрацию, сортировку и трансляцию кодирующих участков.

## Задачи
1. Сформировать единый GenBank-файл на основе данных с сайта NCBI.
2. Отсортировать последовательности по GC-составу.
3. Выполнить трансляцию кодирующих областей (CDS) в белковые последовательности.

## Инструментарий
Язык программирования Python, библиотеки Biopython (`SeqIO`, `SeqUtils`), сайт NCBI ([https://www.ncbi.nlm.nih.gov/]).

## Ход работы
### Задание 1. Формирование исходного файла
С сайта NCBI были выбраны по пять записей в формате GenBank для двух различных видов по запросу название_вида complete cds. Все записи были сохранены в файл `sequence.gb` и объединены в один файл `combined_file.gbk` с помощью Biopython. Проверено наличие не менее 10 кодирующих последовательностей (CDS).
### Задание 2. GC-составы
Из объединённого GenBank-файла `combined_file.gbk` считаны все записи. Для каждой последовательности рассчитан GC-состав, после чего записи отсортированы по возрастанию этого показателя и выведены в консоль.
### Задание 3. Трансляция
Из исходного файла `sequence.gb` извлечены все CDS. При наличии готового перевода (translation) каждая CDS была сопоставлена с координатами и аминокислотной последовательностью. Результаты трансляции сохранены в файл `translations.txt`.

## Выводы 
Получен и обработан единый GenBank-файл с записями двух видов. Научилась извлекать информацию о кодирующих областях, рассчитывать GC-состав и выполнять трансляцию в белковые последовательности. Работа показала, как с помощью Biopython можно автоматизировать задачи первичного анализа нуклеотидных данных.
