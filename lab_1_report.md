# Отчет по лабораторной работе 1 "Смертные кролики Фибоначчи" (Вариант 2)

## Цель
Смоделировать рост популяции кроликов с учётом того, что они живут ограниченное количество месяцев.

## Задачи
* Изменить классическую модель Фибоначчи, чтобы учесть смертность кроликов.
* Написать функцию, которая считает количество кроличьих пар в каждый месяц.
* Проверить, как будет меняться популяция со временем.

## Инструментарий
Для решения задачи использовался язык программирования Python. Основная идея реализована через список (массив), в который по очереди записываются значения по месяцам. Также применён метод динамического программирования, чтобы не пересчитывать одно и то же много раз.

## Ход работы
1. Написала функцию `rabbit_pairs(n, m)`, где `n` — это количество месяцев, а `m` — сколько месяцев живёт каждая пара кроликов.
2. Создала список `dp`, в котором будем хранить, сколько пар кроликов есть в каждом месяце.
3. В первом месяце — одна пара.
4. Для каждого следующего месяца смотрим:
   * Сколько кроликов осталось с прошлого месяца;
   * Добавляем новых, которые родились от тех пар, которым уже исполнилось 1 месяц, но которые ещё не умерли.
5. Провела тест: если кролики живут 3 месяца, а рассматриваем период в 6 месяцев, то получилось 4 пары.

## Вывод
Эта модель более реалистична, чем обычная последовательность Фибоначчи, потому что учитывает смерть кроликов. Видно, что из-за ограниченной жизни рост популяции замедляется. Всё получилось правильно: через 6 месяцев при жизни кроликов по 3 месяца остаётся 4 пары.
