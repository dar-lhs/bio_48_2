# Отчет по лабораторной работе 3 "Представление данных в Python"

## Цель
Научиться визуализировать табличные данные с помощью библиотеки Seaborn, строить диаграммы рассеяния и графики временных рядов, применять фильтрацию и классификацию данных.

## Задачи
1. Ознакомиться с возможностями библиотек `pandas`, `seaborn`, `matplotlib.pyplot`, `statsmodels` для анализа и визуализации данных.
2. Построить диаграмму рассеяния по двум числовым признакам с отображением классов.
3. Разбить один из признаков на интервалы и отразить это в графике с помощью цвета и формы точек.
4. Построить график временного ряда по заданному промежутку времени.
5. Научиться фильтровать данные по дате и оформлять график с подписями и сеткой.

## Инструментарий
* Язык программирования: Python
* `pandas` — для загрузки и обработки табличных данных;
* `seaborn` и `matplotlib.pyplot` — для визуализации;
* `statsmodels.datasets` — для загрузки встроенных датасетов (`cancer`, `co2`).

## Ход работы

### 1. Построение диаграммы рассеяния
* Загрузила датасет `cancer` с помощью `statsmodels.datasets`.
* Выбрала два признака: `cancer` (число случаев рака) и `population` (численность населения).
* Провела классификацию столбца `population` на 3 группы (малые, средние, большие) с помощью функции `pd.cut`.
* Визуализировала данные на диаграмме рассеяния с использованием Seaborn:
  * по оси X — `cancer`,
  * по оси Y — `population`,
  * цвет и форма точек определялись принадлежностью к определённому классу (`class`).
* Настроила заголовок графика и размер фигуры для лучшего восприятия.

### 2. Построение графика временного ряда
* Загрузила датасет `co2`, содержащий ежемесячные значения концентрации углекислого газа в атмосфере.
* Преобразовала колонку с датой в формат `datetime`, убрала пропуски.
* Отфильтровала данные по датам: с 1 января 1958 года по 31 декабря 1980 года.
* Построила линейный график зависимости уровня CO₂ от времени.
* Настроила:
  * заголовок,
  * оси X и Y с подписями,
  * отображение сетки,
  * поворот подписей по оси X для лучшей читаемости.
